## 🌋 OptiMux v1.1.0

### 新機能

*   高度なリサイズと変換レシピの追加
    *   リサイズ, コーデック, コンテナ, CRF を組み合わせた一括変換が可能です.

### 既知の問題・注意点

*   Windows Drag & Drop
    *   Dragging files onto the window initiates a local copy process to a temporary folder (`~/Downloads/OptiMux_Temp`) before processing starts.
    *   This ensures compatibility across Windows environments.
*   Linux版ビルド
    *   本リリースにはLinux用バイナリは含まれていません.
    *   必要な場合はソースからビルドしてください.

## 🌋 OptiMux v1.0.0-rc1

### IMPORTANT: FFmpeg is required

OptiMux does not bundle FFmpeg due to licensing reasons. You must have `ffmpeg` and `ffprobe` installed on your system.

### Known Issues / Notes

* **Windows Drag & Drop:** Dragging files onto the window initiates a local copy process to a temporary folder (`~/Downloads/OptiMux_Temp`) before processing starts. This ensures compatibility across Windows environments.
* **Linux Build:** Linux binaries are not included in this release. Please build from source if needed.
